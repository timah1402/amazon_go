# Amazon Go–style Checkout-free Store — Mobile App

A mobile app for a checkout-free supermarket, inspired by Amazon Go. Shoppers enter the store with a QR code from the app, pick up products, and pay from the app without going through a checkout line.

## Features

- Account creation, login and password change
- Personal QR code used at the store entrance to unlock the door
- Store browsing, product cards and cart
- Payment methods and purchase history
- Address book and notifications

## Tech stack

React Native · Expo (EAS) · Firebase (Authentication, Firestore) · Tailwind

## Getting started

```bash
npm install
npx expo start
```

Native Android and iOS projects are included in `android/` and `ios/`.
